# Screenshots

This folder holds the README screenshots referenced from the main README.

Drop the following PNGs here (or upload via GitHub web UI):

- `screenshot-idle.png` — GUI in idle state (codec dropdown, folder pickers, queue)
- `screenshot-running.png` — GUI mid-encode (CPU/GPU bars, progress, console output)

Recommended size: 1920×1080 or window-sized (e.g. 1340×860 to match the default window dimensions).
